# 통합 레이어 선택 화면 — 2026-11-12

사용자가 제공한 솔라맵 화면과 지정 배치를 구현 기준으로 삼는다. 왼쪽은 벡터타일/TIF 선택 전용, 오른쪽 위는 속도 측정, 오른쪽 아래는 현재 표시 레이어 범례다. 사용자가 이미 위치와 역할을 정했으므로 추가 디자인 승인 단계는 만들지 않는다.

## 구조

- `distance.html`, `distance.css`: 고정 왼쪽 목록, 넓은 지도, 오른쪽 위/아래 접이식 카드. 색상 설정은 대화상자, result 조회는 지도 클릭 시 나타나는 별도 카드.
- `distance.js`: 기존 TIFF·result 조회 및 반복/중단/CSV 동작 유지. 체크박스로 TIFF 하나씩 전환하고 모두 끌 수 있다. 켜진 레이어에 따라 범례를 갱신한다.
- `distance-vectors.js`: 기존 `APP_CONFIG.LAYERS`와 `/tiles/{id}/meta.json`을 이용한 목록 및 MVT 표시. 자료가 없으면 해당 항목에 표시한다. 204 응답은 빈 타일로 취급한다.
- 벡터/조회선 오버레이는 TIFF와 같은 view를 사용하는 별도 OpenLayers 지도. TIFF 렌더 완료 측정이 벡터의 로딩을 기다리지 않게 한다.
- 벡터 현재 화면 표시 시간은 오른쪽 측정 카드의 별도 탭에서 확인한다. 기존 전국 시나리오 화면은 링크로 유지한다.
- 좁은 화면은 목록을 접이식 서랍으로 전환한다. 오른쪽 카드끼리 겹치지 않도록 높이를 제한한다.

5. [x] 벡터 테스트 응답으로 MVT 읽기·빈 타일·오류·측정 분리를 확인한다. 로컬 원본 벡터 데이터가 없다는 한계는 명시한다.
