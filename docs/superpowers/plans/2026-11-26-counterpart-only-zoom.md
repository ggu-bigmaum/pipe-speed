# 첫 관로와 비교 상대만 표시

사용자 확정: 첫 관로는 자유롭게 선택하고 이후에는 첫 관로의 비교 상대만 확대 기준 이상에서 허용한다. 상수 건기연↔서울시, 하수 건기연 서울 보정본↔서울시만 대응한다. 서울 외/참고용 등 비교 상대가 없는 자료는 단독으로 본다. 모든 선택을 해제하면 새 첫 관로를 고를 수 있다. 비교 중 첫 관로를 해제하면 남아 있는 상대가 첫 관로가 된다.

줌 12에서 두 관로만 먼저 실제 테스트한다. 브라우저 종료 재현 시 사용자가 허용한 줌 14로 올린다. TIF에는 제한을 적용하지 않는다. 기존 판정 기준·클릭 조회는 그대로 유지한다.

줌 12 실제 결과: 별도 검증 탭에서 건기연 상수+서울시 상수 두 관로와 서울 상수 Case1 TIF만 켰고, 다른 관로는 잠겨 선택되지 않았다. 상수 비교 표시 요청 후 탭이 응답을 멈추고 `This page crashed`로 전환됐다. 사용자가 허용한 대안인 줌 14를 최종 기준으로 선택한다. OOM 또는 데이터 충돌 중 구체적인 원인은 이 결과만으로 단정하지 않는다.

검증: 모든 첫 선택과 비대응 잠금, 경계, 축소 해제/취소/캐시 정리, 첫 선택 교체, 기존 상수/하수 강조 회귀, 실제 브라우저 두 관로 비교+TIF. 푸시/서버 배포/휴대용 묶음 없음.

실제 줌 14 확인: 새 검증 탭에서 상수 두 자료+TIF 표시 및 완전일치 강조가 보였고, 하수 두 자료+TIF 표시 및 반올림 형상 일치 범례도 확인했다. 줌 13으로 축소하면 두 번째 관로가 해제되고 모든 나머지 관로가 잠기며 TIF는 켜진 상태를 유지했다. 자동 테스트 50개 통과.

남은 제한: 상수 검증 탭에서 줌 14→15→13→11→14로 반복 이동 후 상대를 다시 켜는 과정에서는 탭 종료가 재현됐다. 따라서 줌 14가 메모리 문제를 모두 해결한다고 주장하지 않는다. 잠금 로직은 검증했으나 장시간/반복 축소·확대 안정성 문제는 미해결이다. 첫 관로 자체의 저줌 데이터량, 타일 캐시, 렌더러를 추가 조사할 필요가 있다. 이번 변경으로 첫 관로의 자유 선택을 임의로 제한하거나 원본 데이터를 줄이지 않았다.
