# 상수·하수 겹침 캐시와 단일 표시 구현 계획

목표: 사용자가 승인한 상수/하수 두 조합만 대상으로, 기존 판정은 유지하고 겹침은 검은 선 한 번으로 표시한다. 서버 반영/보고서/이동형 묶음 제작은 제외한다.

- [x] 기존 비교 SQLite의 양쪽 관로 키와 타일 출처를 확인한다.
- [x] 타일별 일치 비트셋을 별도 영속 SQLite 캐시로 저장한다. 원본 타일/비교 DB는 읽기 전용. 버전·입력 타일 변경 시 무효화한다.
- [x] 건기연과 서울시 양쪽 비트셋을 지원한다. 양쪽 대응 타일이 검증된 경우에만 건기연의 겹침 선을 숨기고 서울시 선 하나를 검게 표시한다. 오류/미완료 시 원래 선 보존.
- [x] 두 자료 중 하나를 끄면 원래 색과 전체 관로를 복귀한다. 비교 허용 줌 12와 클릭 조회 및 TIF 유지.
- [x] 캐시 재시작 재사용/입력 변경/동시성, 양쪽 표시/원본 복귀/실패 복귀를 테스트한다.
- [x] 캐시/렌더 부하를 보완하고 실제 로컬 화면에서 확대·축소를 검증한다. 이전 OOM의 단일 원인은 단정하지 않으며 모든 환경의 해결을 보증하지 않는다.
- [x] 단계별 커밋 및 로컬 적용. 다른 PC용 묶음은 실파일 용량만 산정하여 전달한다.
