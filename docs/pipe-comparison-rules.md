# 상수관로 비교상태와 지도 강조 기준

## 비교 범위와 근거

건기연 전국 상수 원본 중 서울 자료와 서울시 상수 자료를 비교한다. 서울 외 지역은 상대 지자체 자료가 없어 `NOT_COMPARED`로 기록한다. 하수 보정 여부와 상수 비교상태를 혼용하지 않는다.

2026-11-11의 방향·연속 길이 보완 결과를 재사용한다. 당시 `comparison_status`는 계산용 후보 분류였으므로 그대로 업무 상태로 표시하지 않는다. 기존 DB는 읽기 전용으로 조사·추출하며 원본이나 기존 결과를 갱신하지 않는다.

현재 원본 전체 선형의 별도 정확 일치 계산도 사용한다. 이 계산은 EPSG:32652에서 허용 거리 0인 2차원 위상적 동일성이다. 방향 반전이나 불필요한 꼭짓점은 허용하지만 위치를 스냅하거나 반올림하지 않았다. 이 결과만으로 불일치 관로의 존재 여부나 부분 대응을 판정하지 않는다.

## 상태 판정 순서

| 순서 | 근거 | 상태 |
| --- | --- | --- |
| 1 | 해당 지역의 상대 지자체 자료가 없음 | NOT_COMPARED |
| 2 | 현재 원본 전체 선형이 정확히 같음 | MATCH |
| 3 | 원본 식별 대응이 미확정, 경계 절단의 영향, 회귀 검토 대상, 대응 구간 경쟁 | CONFLICT + 해당 사유 |
| 4 | 기존 방향·연속 길이 검사 후 합집합 대응 비율이 95% 이상 | MATCH |
| 5 | 해당 검사를 통과한 연속 대응 구간이 일부 있음 | PARTIAL_MATCH |
| 6 | 위 근거로 자동 판단하기 어려움 | CONFLICT + 해당 사유 |

`KICT_ONLY`와 `LOCAL_ONLY`는 실제로 한 자료에만 존재한다고 판단할 근거가 있어야 한다. 기존의 ‘5m 이내 후보 없음’만으로는 확정하지 않는다. 해당 후보는 `candidate_status`에만 남기고 현재 업무 상태는 `CONFLICT`로 기록한다. 여섯 상태를 지원한다는 것이 모든 상태에 반드시 관로를 배정한다는 뜻은 아니다.

관종·재질 코드 해석은 자료별 메타데이터가 확인되지 않았으므로 서로 다른 코드 값을 동일 물성 또는 물성 충돌로 임의 해석하지 않는다. 기존 속성 차이 플래그는 판정 근거와 함께 보존한다. 현재 상태는 자료 간 공간 대응 상태이며 현장 물리적 동일성을 보증하는 값이 아니다.

## 재사용한 방향·연속 구간 규칙

- 거리 1m 이내, 최대 4m의 앞뒤 경로를 고려한 진행 방향 차이 20도 이내.
- 최대 0.25m 간격으로 검사하며 저장 방향은 무관하다.
- 연속 대응 길이 최소 0.5m. 짧은 선분은 더 짧은 구성 선분 길이의 절반을 기준으로 한다.
- 0.05m 이하 틈은 연속성 판단에서만 허용하고 대응 길이에 더하지 않는다. 분리된 MultiLineString 구성 선분은 연결하지 않는다.
- 양쪽에 대응 근거가 있는 관계만 인정한다. 여러 상대 관로가 겹치는 길이는 합집합으로 한 번만 센다.
- 작은 굴곡으로 정상 대응이 사라지는 것을 막는 기존 보완: 양쪽 길이 2m 이상, 길이 비율 및 기존 대응 비율 95% 이상, 고밀도 하우스도르프 거리 0.1m 이내.
- 같은 구간의 중복 대응 길이가 `max(0.05m, 관로 길이의 5%)`를 넘으면 경쟁 후보로 검토한다.
- 기존 95% 이상 대응에서 보완 후 95% 미만으로 바뀐 비정확 일치 관로는 검토 상태를 보존한다.

## 식별자와 중복 관계

원본 객체 키는 `자료 종류 + 원본 파일 SHA256 + source_fid`이다. `ORG_IDN`이나 `PLINE_ID`만으로 원본을 하나로 간주하지 않는다. 이전 비교 내부 ID와 현재 source_fid는 원본 식별자 및 전체 원본 WKB 해시를 모두 대조한 대응표로 연결한다.

기존 상수 MVT는 원본 source_fid를 보존하지 않고 식별값·관경·재질 세 속성만 담고 있다. 세 속성을 묶은 키가 원본 여러 개에 대응하면 원본 후보를 모두 제시한다. 임의의 첫 번째 관로를 골라 결과를 붙이지 않는다. 타일 선형의 양자화나 짧은 선 확대를 원본 비교 계산에 사용하지 않는다.

## 지도 자동 강조

`exact_same_id_geometry`는 **원본 관로 ID가 같고 원본 전체 선형도 정확히 같을 때만** 참이다. 업무용 `MATCH`와 별도 값이다. 상당히 유사해서 `MATCH`인 경우, 부분 대응, 단순 교차는 자동 강조하지 않는다.

건기연 상수와 서울시 상수를 함께 켠 경우에만 강조한다. 동일 위치를 두 번 그리지 않도록 서울시 선 위에 자동 강조 스타일을 적용한다. 클릭한 관로의 빨간 선택 표시는 계속 최상단에 둔다. 어느 한 레이어를 끄면 자동 강조가 사라진다.
