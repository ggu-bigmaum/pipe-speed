# 하수 원본 전환 · 서버 업로드

서울 하수는 기존 보정본을 유지하고, 서울 외 하수는 원본을 사용합니다. 전남은 원본 자료가 없어 제외합니다. 상수 결과는 기존과 같습니다.

`C:\Users\admin\Desktop\빅마음\03_Dev\02_Web\pipe-speed\backend\data\upload_original_sewer_20261125`

- `pipe-sewer-original-tiles-20261125.tar.gz`: 서울 외 원본 하수 타일 + 기존 서울 보정 타일

## 2. 서버 터미널 — 코드와 데이터 반영

원본 전환 코드가 Git에 푸시된 뒤 실행합니다. 이번 작업은 로컬 적용과 데이터 준비까지이며, 코드 푸시와 서버 반영은 아직 수행하지 않았습니다.

```bash
cd /home/bigmaum99/demos/pipe-speed
git pull --ff-only
bash tools/install_original_sewer_data.sh
sudo systemctl status pipe-speed.service --no-pager
journalctl -u pipe-speed.service -n 30 --no-pager
```

스크립트는 압축파일 해시와 구성을 확인한 뒤 서비스를 잠시 멈추고 교체합니다. 기존 파일은 `backend/data/.previous-original-20261125.*`에 남기며, 교체 실패 시 되돌립니다. 데이터 설치가 끝나면 서비스를 다시 시작합니다. 새 Python 패키지 설치는 필요하지 않습니다.
