# 상수 관로 비교 화면 사용·반영 안내

## 화면에서 확인하는 방법

1. `건기연 상수` 또는 `서울시 상수`를 켜고 관로를 누르면 비교상태, 근거, 상대 관로를 조회한다.
2. 두 상수 레이어를 함께 켜면 **원본 ID와 원본 전체 선형이 모두 같은 관로만** 노란색과 짙은 테두리로 강조한다.
3. 어느 한쪽을 끄면 자동 강조가 해제된다. 클릭 선택은 빨간색으로 별도 표시한다.

`MATCH`에는 상당히 유사한 관로도 포함되므로 모두 노란색이 되는 것은 아니다. `PARTIAL_MATCH`나 단순 교차도 자동 강조하지 않는다. 대응 목록의 관계는 선택한 관로와 상대 관로 사이의 관계이며, 상대가 다른 관로와 일치하는지를 가져와 표시하지 않는다.

원본 ID가 중복이면 원본 객체 번호를 함께 표시한다. 현재 타일의 속성만으로 하나의 원본을 특정하지 못하면 후보 선택을 요구한다. 임의로 첫 번째 후보의 상태를 붙이지 않는다.

## 비교 대상과 판정 범위

- 비교 대상: 건기연 전국 상수 4,440,047개, 제공 서울시 상수 1,444,804개.
- 서울 외 건기연 상수는 상대 지자체 자료가 없어 `NOT_COMPARED`로 저장했다.
- 기존 서울 비교의 방향·연속 구간 결과와 현재 전체 원본의 정확 일치 결과를 함께 사용했다.
- 가까운 후보가 없다는 이유만으로 한 자료에만 존재한다고 확정하지 않았다. `KICT_ONLY`·`LOCAL_ONLY` 후보는 근거 확인이 필요한 `CONFLICT`에 남겼다.
- 하수 보정, 원본 선형, 기존 운영 DB 및 벡터타일 파일은 변경하지 않았다.

| 자료 | MATCH | PARTIAL_MATCH | CONFLICT | NOT_COMPARED | 합계 |
|---|---:|---:|---:|---:|---:|
| 건기연 상수 | 1,419,830 | 7,373 | 18,237 | 2,994,607 | 4,440,047 |
| 서울시 상수 | 1,422,503 | 7,455 | 14,846 | 0 | 1,444,804 |

현재 확정된 `KICT_ONLY`·`LOCAL_ONLY`는 각각 0개이다. 여섯 상태 지원과 모든 상태에 실제 사례가 존재하는 것은 별개이다. 자세한 기준은 [판정 규칙](pipe-comparison-rules.md), 집계·출처는 [검증 기록](comparison-validation.json)을 참고한다.

## 별도 데이터 파일

코드와 별도로 다음 두 파일이 필요하다. 기존 관로·거리 자료는 그대로 사용한다.

```text
backend/data/comparison/water/
├─ water_comparison.sqlite
└─ manifest.json
```

로컬에는 두 파일을 설치했다. SQLite 크기는 2,061,524,992바이트이며 무결성 해시는 manifest와 서버가 대조한다. 데이터 폴더는 Git에서 제외된다.

사용자가 서버에 반영할 때 실행할 PowerShell 명령:

```powershell
scp -r "C:\Users\admin\Desktop\빅마음\03_Dev\02_Web\pipe-speed\backend\data\comparison" "bigmaum99@220.95.232.173:/home/bigmaum99/demos/pipe-speed/backend/data/"
```

코드가 원격 저장소에 올라간 이후 서버에서 갱신하는 명령:

```bash
cd /home/bigmaum99/demos/pipe-speed
git status
git pull --ff-only
sudo systemctl restart pipe-speed
sudo systemctl status pipe-speed --no-pager
```

이번 작업에는 원격 푸시와 운영 배포를 포함하지 않았다. 위 명령은 서버 반영 시 사용할 안내이다.

## 성능·표시 경계

강조용 정보는 현재 타일의 순서별 판정 비트로 전달하며 전체 원본 선형을 브라우저에 다시 보내지 않는다. 브라우저가 받은 타일 해시·객체 수·비교 결과 버전이 모두 맞을 때만 적용한다. 자료가 누락되거나 판정 정보가 잘못되면 기본 관로 색은 유지하고 강조 오류를 표시한다.

타일의 짧은 선 확대 및 양자화는 기존 표현을 유지한다. 노란색은 **원본 전체 선형**의 검증 결과이며, 타일에서 보이는 개별 조각의 새 공간 비교 결과가 아니다. 저배율 대용량 원본 타일 자체의 기존 메모리 문제를 해결한 것으로 해석하지 않는다.
