# 거리 래스터 테스트 — 2026-11-12

사용자가 추가한 TIF 2개와 result를 같은 지도에서 확인하고 원본 TIF의 표출 시간을 측정한다.

- 기존 관로 화면에서 `거리 래스터` 화면(`/app/distance.html`)으로 이동한다.
- Case 1/2 선택, 표시 여부, 투명도, 색상 구간, 서울 전체 범위 버튼을 제공한다.
- 서버는 원본 TIFF를 그대로 전달한다. 브라우저 OpenLayers가 GeoTIFF를 읽고 EPSG:32652에서 웹 지도로 재투영한다. NoData는 투명, 유효한 0은 색상으로 표시한다.
- 기존 네이버 키가 있으면 네이버 배경을 유지한다. 키가 없으면 OpenStreetMap 배경을 쓰며 화면에 표시한다. 배경 지도 요청은 래스터 측정에서 제외한다.
- 격자 클릭은 원본 격자 DB에서 확인한 `grid_id ↔ 행·열` 대응표로 result와 연결한다. 엑셀 순서나 거리값으로 대응을 추측하지 않는다.
- 조회에는 두 거리값, 통과 여부, 관로 ID(문자열), 최근접점 좌표를 표시한다. 격자 중심·최근접점은 지도에 구분하여 표시한다.
- 원본 다시 읽기는 브라우저 HTTP 캐시를 우회하고 GeoTIFF 소스를 새로 만든다. 다운로드, 해석·표시, 합계 시간을 구분한다. 서버 OS 캐시까지 지웠다고 주장하지 않는다.
- 이동·확대의 다시 그리기 시간은 이미 읽은 래스터의 재표시로 별도 기록한다. 반복 측정, 중단, CSV 저장을 제공한다. 실패·탭 비활성 상태를 성공 측정으로 기록하지 않는다.

## 구현 및 검증 순서

1. 실제 입력 3개의 해시와 격자 위치 대응표를 확정한다. 모든 result ID가 한 격자에 대응해야 한다.
2. Flask 테스트로 메타·원본 파일·격자 조회·경계/NoData·숫자가 아닌 ID 보존·파일 오류 응답을 먼저 정의하고 실패를 확인한다.
3. 독립 Flask blueprint와 캐시된 read-only Excel 조회를 구현한다. 파일 경로는 허용 목록으로 제한한다.
4. OpenLayers 번들을 고정 버전으로 빌드하고 독립 화면 및 기존 화면 링크를 추가한다.
5. 실제 브라우저에서 두 사례, 클릭, 0값, 색상 변경, 재로딩, 반복·중단, CSV, 화면 크기를 확인한다. 기존 /health 및 기존 화면도 확인한다.

원본 TIF·엑셀은 수정하지 않는다. 이번 결과는 원본 파일 방식이며 줌별 파일 분할은 적용하지 않는다.
